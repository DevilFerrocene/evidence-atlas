# Evidence Atlas

交付能让读者学会论文论证的完整双语读本。读者有基础数学与一般理工知识，但未读过前作。全文翻译、逐句讲解、实际文献调查分别完成；工具发布成功只表示内容已落盘。

## 一次任务中的连续目标

本 skill 按通读、文献调查、正式写作三个阶段，由同一作者连续完成。通读后先建立并完成文献调查 goal，再开启第一轮写作 goal，完成完整读本后立即开启第二轮深化回读 goal；第二轮回读属于写作阶段，结束后才最终交付。两轮共享已经读取的原文、来源、研究判断及工具 ID；自动压缩后从本轮进度接续。不是输出两次答案，也不另派修复代理。

首次阅读本目录 references/reader-reference-einstein.md 的三处节选和 references/explanation-examples.md。工具仍使用任务指定的 Evidence Atlas 项目 scripts/atlas-call.mjs；不调用默认 paper-worker 契约替换本 skill 的两轮安排。下文科学写作要求适用于两轮，第二轮另有明确深化任务。

通读完整原文、公式、脚注与书目后，立即 create_goal 建立“集中调查主论文关键问题及上游原始依据”的真实目标，按下述文献调查要求实际阅读并保存结果。调查阶段完成后结束该目标，在同一次工作中立即 create_goal 建立“第一轮：基于已读材料完成整篇初稿及保存”的真实目标，不等待用户继续。一次列齐所有自然段小目标，一个自然段一个小目标；不合并多段，不做完一个才创建下一个。行间公式与所属段落一起处理，以原页自然段而非 OCR 块数划分。单活动 goal 接口用本地清单记录全部段落小目标及状态，不模拟嵌套工具。

第一轮按顺序逐段翻译、逐句解释、研究实际借用的前作、保存并回读，标记当前段完成后立即进入下一段。不得先批量铺完全文再回填。第一轮须形成有实质讲解与引用的完整读本，不能把应做的研究全部留给第二轮。全部段落完成后通读并导出第一轮单文件，保存为 first-pass/paper.json，后续保留这个快照用于对照。实际完成第一轮目标后 update_goal(complete)，在同一次持续工作中立即 create_goal 建立第二轮目标，不发送 final，不等待用户说继续。

第二轮目标为“逐段深化原始证据链、核算公式、调整本科中年级讲解并交付整篇”。重新一次列齐所有自然段的第二轮小目标，状态从待做开始。第一轮已完成清单不能代替第二轮清单；发布成功也不能代替科学深化。通读初稿后逐段执行下列第二轮任务，保存、回读并标记，再进入下一段。

文献调查和两轮写作均不因预计 token、上下文容量或压缩边界主动终止。保存轮次、段落位置、已读材料、工具 ID 与待解问题，压缩后接续。goal 接口实际不可用时记录事实并按同样的两轮清单持续工作。工具不设置阶段门，来源访问缺口集中保留并继续其他分析。

## 先通读、再调查、再写作

完整任务按三个阶段连续推进：通读主论文，集中调查相关文献及其上游依据，然后正式逐段逐句写作。写作完成后的深化回读属于第三阶段，不用它代替写作前的文献研究。

通读时理解主线、公式、实验和引用，辨认关键结论借用了哪些理论、方法、数值与观测，形成需要查清的具体问题。此时可以记录理解和定位，不先生成整篇正式讲解再给现成结论找依据。

正式写作前，围绕这些问题实际阅读对应的参考文献 B。读 B 的相关正文、公式、实验、脚注和引文；B 把关键依据交给 C，就取得并阅读 C，再按需要追到 D，直到找到原始证明、观测、实验或明确假设。主动检索独立研究交叉验证，并为拟加入的现代解释补充相应来源。综述和教材可以帮助理解与定位前作，不能自动替代原始证据。

复用工作区现有来源和续作记录，集中保存具体科学结果、适用条件、原文位置、已解决问题与剩余缺口。保存真实的依赖关系并读回确认；书目身份和引用关系不等于已核实的科学支持，不把未取得的证明标成已得到。无须为每个问题建立额外文件，也不必通读参考文献表中的所有论文；按关键问题深入阅读相关部分，不设篇数或层数配额。

主要论证所需的资料已实际调查、已读结果和真实缺口清楚后，进入正式写作。有效线索尚在且关键问题未查清时继续追查；个别来源确实取不到时，将访问情况集中留在来源详情，按实际证据范围写可完成的部分，不让一篇受限文献冻结整篇工作。写作中发现新问题，随时返回调查。工具始终可自由读取、保存和修正，不设置阶段调用门槛。

## 第二轮的具体任务

文献列表不等于证据依赖链。逐个检查关键命题：当前节点是否借用了另一个节点的结果；若是，使用工具返回的真实 ID 保存 depends_on，并读取保存结果确认关系存在。所有节点都为空时，逐项辨认是否遗漏了本文使用前作、前作使用更早结果的关系。原始实验或直接推导确实没有上游依赖时可以为空，不为消除空数组虚构关系或凑层数。取得上游文献后，让它的具体结果进入讲解与相应链接。

鼓励充分展开公式与长篇讲解。篇幅由理解困难决定，不把每个入口限制成两三句话。值得推导的关系，写清起点、假设、代入、中间变形和物理含义，必要时讨论量纲、极限及例子。短论文可能需要长解读；连贯的长篇讲解可以保留，避免重复总结和无关扩写。

每段围绕具体科学句意检查初稿：它用了什么定义、假设、观测或外部结果，读者从当前解释能否理解为什么成立。保留有实质价值的讲解，补足漏掉的独立句意和关键中间步骤；简单过渡句可不解析。不以整段总结代替逐句入口，不为显得改动充分而重写已经准确清楚的内容。

第二轮要主动扩大与讲解有关的文献调查，不能只重读本文和第一轮已有的少数来源。检查每个重要解释实际借用了哪些知识：理论关系、实验方法、数值、判别标准、历史归属，以及自行补充的现代解释；为尚缺具体依据的内容检索并实际阅读相应研究。优先原始论文，综述和教材可以帮助建立背景、理解术语与找到前作，但不能自动替代原始证据。增加来源的目的，是补上推理中缺失的联系，而非凑文献数量。

必须查“文献的文献”：读到 B 后，读取与当前问题有关段落的引文、作者脚注和参考文献，辨认 B 把哪些关键依据交给了 C，随后取得 C 并读其具体论证；C 若再借用 D，就继续。不能找到标题、取得摘要或导入 B 后便把这一分支标为完成。遇到表述含混、条件不明或缺少关键论证，还应检索独立研究交叉验证；不要仅在本文参考文献表内打转。无实际引用关系的补充研究按补充或交叉验证使用，不虚构历史依赖。

新读文献的结果要进入对应讲解：说明它解决了什么疑问、提供了什么推导或实验结果、适用条件是什么，并就近引用；实际借用关系保存为 depends_on，读回确认。已有证据节点仅为摘要或书目时，继续寻找正文和可用原始来源；真实访问缺口集中留在来源详情。对确已读到原始证明、观测或明示假设的分支可以结束，不要求固定篇数或层数；对仍有实质疑问且存在有效检索线索的分支继续调查。

重点调查初稿依赖的外部结果。对 A 使用的 B，实际阅读 B 提供该结果的论证、实验、公式与相关引文。B 若把关键依据交给 C，随即取得并阅读 C；C 再依赖 D，就继续，直到找到当前命题的原始推导、观测、实验或明确假设。不要以导入成功、摘要、书目条目或 A 的转述关闭尚未解决的问题。条件含混或证据冲突时，可查参考文献表之外的独立研究作交叉验证。没有固定文献数或链条层数；自行推导能补代数，不能补出未取得的实验事实。

让调查改变讲解本身：具体说明 C 得到什么，B 怎样使用它，本文又怎样借用或限制这个结果。把相关条件、方法和结论讲给读者，而不是列论文名字。只记录实际成立的依赖关系：使用 B 的证据节点指向 B，B 使用 C 的节点再指向 C；独立交叉验证和后来发展按真实关系连接，不冒充原作者引用。复用读过的来源和位置，发现新的相关问题时再补读。

在使用他人结果的具体句子旁写出自然归属和数字引用，例如“按照某某的测量结果 [2](evidence:实际ID)，……”。同一来源复用同一编号，不同位置可链接该来源的不同证据。保留原文及译文的原始引用标记与书目；新增解释引用另按实际来源组织。保存后的解释、引用链接和依赖节点要相互对应，不能只在来源表里增加论文。

讲解面向本科中年级：具备本专业基础课和基础数学知识，但未学过本文专门方法。首次出现的专门概念，在当前推理需要的位置解释其含义、怎样使用和为何有关。将长难句拆成相互承接的句子，用自然中文讲清观测如何支持判断、假设怎样支撑推导。保留科学深度和句意密度，必要时增加中间式、具体例子或有价值的相关研究；不靠删除困难内容降低难度，也不泛泛补写无关教材。每个解释入口是一块连贯讲解，可含自然段和公式；无标题、小标题、QA、自问自答或固定栏目。

核对实际保存的公式和数字，而不是脑中熟悉的正确版本。原文公式对照原页；把稿中定义与取值原样代入，检查下一步是否成立。新增推导独立重算，检查符号、共轭范围、单位、近似、边界和极限。物理量定义与后续计算保持一致，避免同一因子既并入定义又乘一次。自行推导、原文结论、现代补充和间接转述通过自然归属区分；证据支持到哪里，论断就写到哪里。

来源访问情况集中保存在对应来源或证据的访问详情。讲解正文和科学 finding 不夹杂下载失败、403、检索过程、“不能冒充已读”或“已核验”等工作说明。实际读到的是转述，就引用转述来源并自然说明归属；只能支持较窄判断，就收窄表述。影响科学结论的未知条件仍需在讲解中清楚说明，其具体访问记录由来源链接承载。有效检索线索尚在时继续调查，真实缺口保留后继续其他可完成的分析。

每段保存后回读该段全部解释：逐句贡献是否得到实质解释；外部判断的就近引文是否齐全；B 留下的问题是否继续查过；查得的结果是否进入文字和依赖关系；公式是否前后一致；本科中年级读者是否能顺着句子走完推理。发现问题就在当前段修正，再标记该小目标完成。此回读由作者完成，不另派审计或修复代理。

第二轮所有段落完成后，通读最终稿，统一术语、引用编号和跨段衔接；导出实际修订后的统一单文件，再结束第二轮 goal 并最终答复。第一轮快照与第二轮结果都交付路径。确实无需改动的段落可保留；有缺口的段落须实际调查和处理，不能只检查结构或复制发布初稿就称为完成第二轮。具体剩余缺口简明列出，访问过程留在来源详情。

## 写作单位是具体科学句意

沿自然段读正文，辨认每个科学句子在论证中贡献什么：定义、假设、条件、比较、观测、借用关系、运算或结论。每个贡献都有自己的解释入口；一句包含不同贡献时可按完整分句细分。纯过渡、行文预告、没有新用途的重复可以不解释，原文仍保留。公式引导语和公式构成一个理解步骤，不能只圈“由此得到”制造入口。

对当前句意实际写完一段专业讲解，再继续后面的句意；研究和保存可以交错，也可以返回完善。批量调用只是存储办法，不把完整讲解压成数组中的一句摘要。不要给所有已翻译段落套同一个循环，自动生成“整段锚点＋两句总结＋本文证据”的读本。

解释首句直接交代本句的物理或数学关系；后续段落把读者缺少的联系展开。定义说明怎样使用，条件说明它保证哪一步，观测说明如何区分可能解释，推导展示实际中间式。连续几个命题相互承接，不能把它们合并成中心思想，也不能为不同句子重复同一份概述。

例如“平均值为实数”“方差非负”“零方差对应确定值”是不同理解步骤。写“厄米性保证这些性质”只是列结果。应根据当前论文的定义，在相应入口真正展示取共轭、移动算符或范数为零怎样分别产生结论。此例说明展开方式，不是指定新论文必须出现这些命题。

深度取决于具体困难。对“代入、相消、分部积分、比较系数”，把被代入的量、运算后的中间式、所用边界或近似条件写出来。亲自把这些关系算一遍，检查符号、复共轭、因子、量纲和极限是否自洽；不能用流畅文字跨过算不出来的一步。原式可疑时回到扫描或公式原图，区分转录错误与原作问题。替代证明可以辅助讲解，但说明它与作者路线的关系，不能冒充原文。

核对对象是读者实际看到的公式。把保存稿中的定义和取值原样代入保存稿中的上一式，逐步检查能否得到下一式；不能凭熟悉的定理在脑中补回遗漏符号。复共轭须核对作用范围，内积须保持同一约定，分部积分须按该约定重新算出体积分符号与边界项。即使某项最后取零或绝对值使最终结论不变，中间等式也必须正确。另一套正确证明不能代替原文路线的校对。原文转录回到原页检查，自行补出的推导则独立重算；正文和证据引文复制同一个公式不构成独立验证。修正转录时同步检查译文、锚点及引用该式的证据，避免不同位置保留矛盾版本。

公式周围的名称也要与数学对象一致，例如标准差乘积与方差乘积具有不同量纲。先处理公式和新增推导，再润色措辞。新术语第一次使用时就地解释其在当前步骤的含义；不能刚从基础定义讲起，就无铺垫地用“紧支撑”“bra”“最高权态”等术语跨过困难。解释术语为继续推理服务，不降低原有逐句密度，也不把正文扩成无关的入门教材。

## 核心结论的自由延展

论文产出核心结论时，允许在逐句讲解的基础上充分延展。值得深讲的结论可以用较长篇幅说明它怎样形成、解决了什么困难、与哪些研究相连，以及它带来的物理图像、推论、应用、局限、争议或其他有价值的认识。相关论文不受原文参考文献列表限制；可以主动寻找更早、同期或后来的工作，帮助读者把结论放回更广的研究脉络。

这是一项自由度，不是每篇论文或每个结论的必填任务。由当前结论的价值与读者的理解需要决定是否展开、展开什么及写多长；不套固定栏目，不规定篇幅、文献数量或延伸主题。让论述沿有意义的联系自然发展，允许作者充分表达有依据的洞见，不为凑扩展而重复正文或堆砌背景。

延展可放在对应结论的解释入口，以连贯自然段展开，仍不设 QA 或解析小标题。它不替代其他科学句意的讲解，也不打乱用户指定的逐段写作顺序：处理到结论时再展开，必要时回溯已读依据。引用他人结果就近标明实际来源；新增相关工作如实说明其与结论的联系，区分历史依据、后来发展、类比与作者自己的推演，不把后来工作写成原作者使用过的前提。文献依赖只记录真实支撑关系，不把所有相关论文机械串成一条倒查链。

## 原始文献调查与讲解共用一条推理

围绕当前命题真正借用的输入找文献。本文提到某作者的发现、某书的证明、某篇前作公式时，本文的引用句只是线索，不能充当外部结果的原始依据。实际取得相应原作，读到具体论证或实验，再将所得内容用于当前句的讲解。

连续倒查是用户明确要求的交付内容。读到 A 时区分它当场推导的结果、明确设定的前提、从 B 借用而未展开的关系。取得 B 后，实际阅读与当前命题有关的论证、公式、实验及引用，判断 B 是否解释了关键依据；不能以“找到 B”或“已导入一篇上游文献”结束调查。

如果 B 仍把关键依据交给 C，随即读取 B 的对应参考文献或作者脚注，解析 C 的身份并取得相关原文，继续分析。C 若又依赖未展开的 D，沿同样方式继续，直到读到该命题的原始推导、观测、实验或明示的假设。只是省略代数时可自行展开；不能用自行推演代替缺失的实验依据或前作归属。没有固定层数，也不凭年代最早判定终点。

如果 B 的解释含混、证据不足、条件不明或与其他结果冲突，主动寻找能解决该具体疑点的独立文献 D 作交叉验证；D 不必在 B 的参考文献中。比较它们的对象、假设、方法和结果，说明 D 支持、限定或反驳了什么。沿引文追 C 与独立查 D 可按实际需要分支进行，不要求每个命题机械执行两条路线。交叉验证不替代仍未查明的历史来源，也不能虚构 B 引用了 D。

上游文献与主论文使用相同的读取能力：已导入 B 时可用 atlas_read_article(article_id=B, view="references") 读取其书目、脚注与引用线索；文献缓存可用 literature_read_saved 的 references 字段。按 DOI、标题或链接取得 C 后继续读取其相关正文与参考文献。接口未暴露或参考文献抽取不全时，直接检查已保存全文、原页或其他可用检索入口。复用已读来源和相关位置，不为每个句意重新下载或通读同一篇文献。

“本文是一手论文”不能关闭其借用的上游分支。本文内部步骤保留依赖，但内部节点数量不等于跨文献调查。不能批量给所有证据填写相同的“本文已推导，故停止”，尤其不能将综述前作的段落标成原创证明。

用户只提供主论文是正常起点，不是调查范围的上限。写作任务包含检索原文提到的前作；“前作未随附件提供”不是访问失败或停止理由。使用当前已授权的文献检索和公开网页工具自行取得。

来源可从现有 scientist-literature 工具、已存缓存、公开原刊、作者稿或网页取得。先核对标题、作者与年份；摘要只支持摘要实际包含的内容，PDF/HTML 读取成功不等于全文完整。查询不到与没有尝试不同；有效线索仍在时换合理入口。真实访问缺口记录在相关来源中，不用自说自话填补。

来源访问情况集中写在相应来源详情或证据的访问范围、终点说明中，同一来源复用一份记录。原文译文、解析正文和科学结果 finding 不写下载、403、开放入口、检索尝试、工具状态，也不反复声明“不能冒充已读”“不伪造逐字论证”“已逐式核验”。访问缺口必须准确保留，但不插进每段科学讲解。若间接来源影响归属，正文自然写“Robertson 转述 Condon 认为……[n]”，让引文指向实际读到的转述来源；只有摘要支持时将命题收窄到摘要实际内容。关键论证缺失时，不把推测写成确定结论，必要时简明指出科学依据尚缺什么，并由引用链接承载具体访问记录。

每个引用只支撑它实际覆盖的命题。用自然行文区分原文陈述、依据明示前提自行推导、现代补充解释和间接史料，例如“由此式展开可得……”或“在现代记号下……”，不增加固定分类栏目或 AI 工作标签。本文讨论统计散布，并不能单凭这一点推出排除隐藏变量等更强的解释立场；超出原文论证的判断须另有相应依据并说清适用范围。证据中的方法说明只记录实际操作与具体位置，不能将读取原页写成核验了整段所有推导，也不能用 supported 等状态覆盖尚缺依据的延伸判断。

atlas_import_source 摄入已取得的外部来源，不必翻译整篇上游论文。atlas_record_evidence 保存具体原文位置、该位置提供的结果与 depends_on。后文 B 使用 A 的结果时，B 的节点指向 A 的节点；不能仅将两篇并列在来源表。现有证据通过返回的 evidence_id 更新，新证据省略 evidence_id 创建，随后复用返回值。

讲解将调查所得写成具体科学联系，例如“C 的实验在这些条件下得到……，B 据此采用……，本文再用它推出……”，在相应结果旁标明文献。保存 A 依赖 B、B 依赖 C 的真实证据关系；独立验证 D 单独连接到它实际支撑的命题，不串成虚假的历史引文链。读者既能顺着讲解理解结果怎样成立，也能反向追到具体原文位置。实际引用、理论来源追溯与后来教学补充分别如实表述。需要补充 finding 时写具体科学结果；准确引文已足够表达且无需另述时可省略，不填写“本段提供依据”等模板。终点理由写真实前提或缺口，不写自评。当前句意回读时确认：关键借用结果是否仍只由本文转述支撑，B 留下的问题是否实际追查，取得的 C 或 D 是否真正进入讲解与证据关系。真实访问缺口留在相关来源详情，继续其他可完成的分析，不将缺口标成已追到原始证据。

## 忠实的双语正文

保留完整自然段、标题、公式、图表文字、作者脚注、书目与句内引用标记。PDF 页和 OCR 行不是段落；先看原页的文章边界、分栏、跨页续文及脚注，不把相邻论文和导航译成本篇。转录后的正文必须仍能与原页逐处对应。

数学符号、复共轭横线、上下标、不等号、因子和作者编号都是原文内容。以原页确定符号，再转成数学格式；不依据想当然的证明静默改写原式。作者姓名、日期及署名信息保留。图版缺面板时补取原图，真实缺口保存在图像来源信息中。取不到位图仍保留图编号、图注、来源链接与缺图状态，不为发布将图注降类为正文或删除图记录。

原文的引用单位是“句内标记 → 对应书目或作者脚注”。两端在中英文正文中都可见。原刊每页重新编号、星号等保持其原有关系；必要时用页码消歧，不擅自改成统一连续编号并称作原刊编号。所用译本遗漏原刊引文时，据实际核对的原刊恢复，并在注中说明版本来源。解析新增引文不替代原作引用。

先按自然中文写中文解释，再写语义与条件一致的英文，使用具名 zh/en 字段。中文避免逐词翻译、长串代词、未解释的外语术语。只讨论影响科学理解的限制，不插入工具、审阅或访问过程。

## 无 MCP 时的直接调用

默认使用 `node scripts/atlas-call.mjs WORKSPACE TOOL -`，通过带引号的 heredoc 将 JSON 直接传入标准输入，无须创建 read-*.json、a-*.json 等一次性参数文件。已有参数文件仍可作为最后一个参数读取。长文本可直接放在 JSON 中；含大量公式或需要反复编辑时再使用下述文本文件引用，避免为每次调用新增文件。`node scripts/atlas-call.mjs --describe atlas_annotate_article` 可读某个工具的输入，不必探索实现或临时写 JavaScript 适配器。

长译文、解释与含数学的锚点直接写成 UTF-8 文本文件，保留一个反斜杠和真实换行。在参数 JSON 的相应字符串位置使用 `{"$text":"drafts/explanation-zh.md"}`；相对路径以 WORKSPACE 为根。脚本只读取文本并传给同一工具，不修改内容、不安排工作顺序。任意层级的字符串字段均可引用文件。例如 explanation 为 `{"zh":{"$text":"drafts/e1.zh.md"},"en":{"$text":"drafts/e1.en.md"}}`。短普通文字可直接写在 JSON 中。用 apply_patch 或带引号的 heredoc 写原样文本，不经过脚本字符串二次编码。

一个解释文件写完完整专业讲解，另一个字段保存其精确句意锚点。一个文件不等于一个原文段落，也不等于限制一段只能有一个入口。文件组织按需要决定；存取入口不决定研究粒度。

## 排版与存储

解析无标题、小标题、QA、自问自答或重复的 summary/why/limits 栏目。一个入口是一块连贯正文，可含多个自然段和行间推导。原论文标题照常保留。不写“AI 整理”“有据可循”“已核验”等邀功文案。

正文与解释采用行内 `\(...\)`、行间 `\[...\]`；多步公式用 aligned。JSON 中反斜杠必须正确转义，脚本字符串使用能保留反斜杠的写法，如 Python raw string 或 JavaScript String.raw；由 JSON 序列化器编码。不要把 TeX 直接塞入会吞反斜杠的字符串。保存后查看实际文字与渲染，特别留意 tab、form-feed 和 carriage-return 是否来自误解码的 tau、frac、right。

atlas_prepare_article 导入主文一次，atlas_save_translations 保存译文，atlas_annotate_article 保存句意锚点和解释。annotations 数组支持同一段多个独立入口。锚点覆盖完整科学句意及完整数学定界，不只圈开头几个词。翻译变化时，可在同一次标注调用中传 translations，使锚点和译文一起更新。

锚点不匹配时，以实际保存文本定位或修正误写的译文；不要为消除报错把全部锚点扩大为整段，更不能删掉数学定界。现有 claim_id 更新对应入口，未提及入口保留。不手工生成最终 bundle JSON。

atlas_repair_import 用于块类型、作者脚注、书目、图文关联和页面杂项。atlas_attach_figure / atlas_mark_figure 用于实际图版。读图后才描述或标记，不能把截断网页截图当成完整原图。

解析就近引用形如“按照某某的工作 [2](evidence:e2)”。编号按来源首次出现分配，同一来源复用编号，每个链接定位到实际支持该处的证据。使用真实工具返回 ID；范例中的语义 ID 只用于示意。数字引文与独立可展开的依赖链同时保留。

## 作者完成的是读本，不是工具调用

发布前后都可返回修改，工具不审批科学结论。作者回读连续段落对应的已保存解释，看读者是否能按已给出的关系重建推理，并在保存的依赖与来源中找到前作提供该结果的位置。逐段处理不以阅读器预览为条件。发现转录错、缺步骤或误引，自己修好这一轮内容，不另找修复代理。

结构检查、文件保存、入口数量和没有报错不能说明质量合格。按连续阅读判断：是否仍有多项科学贡献只得到一条短摘要；关键“所以”前是否已有充分中间关系；借用前作是否实际读到；每个声明的核对是否真的做过。完成后返回实际读本地址和具体遗留缺口，不用自评替代结果。
